## About

I build practical desktop software focused on **performance analysis, automation, data visualization, and local AI workflows**.

My current flagship project is **FrameView Analyzer**, a native Windows application for analyzing **NVIDIA FrameView** and **NVIDIA App** performance logs in a clean benchmark workspace.

### 🎯 [FrameView Analyzer](https://github.com/StreckerMX/FrameView-Analyzer)

A native **Windows / .NET 10** application for analyzing and comparing NVIDIA FrameView captures and NVIDIA App performance-overlay logs.

**Highlights:** interactive performance charts, Pair and Multi comparison, visible-range statistics, benchmark library, filtering, automatic analysis, and presentation-ready PNG exports.
